# giuseppelupo1979/tap

Homebrew formulae by Giuseppe Lupo.

| Formula | Description |
|---|---|
| [aggiornamenti](https://github.com/giuseppelupo1979/aggiornamenti-mac) | Local web page that finds outdated Mac apps and updates them silently |

```bash
brew install giuseppelupo1979/tap/aggiornamenti
```

If Homebrew says the tap is not trusted:

```bash
brew trust --formula giuseppelupo1979/tap/aggiornamenti
```
